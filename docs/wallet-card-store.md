# 钱包卡网模式

1. 在 `/redemption-codes` 建立卡密分类并设置档位面额；需要赠金时，在赠金规则中为该分类指定比例。未设赠金规则的档位仍展示，赠金额度为零。
2. 使用超级管理员账号，在 `/system-settings/billing/payment` 确认现有支付合规条款。在「钱包充值模式」打开「卡网模式」，填写可公开访问的购卡页面完整 URL，点击「保存全部设置」。支持 HTTP 和 HTTPS；不要使用管理后台、一次性结算或含凭据的链接。
3. 用户打开 `/wallet`，可查看各档位的面额和预计赠金额度，在内嵌卡网购卡，再使用钱包内的兑换框兑换。档位以 `/redemption-codes` 为准，按面额排序，刷新钱包即可看到更新。钱包不查询或公开库存卡密，也不会因为打开网页或完成外站付款就增加余额；只有本站兑换成功才增加主余额和相应赠金。
4. 卡网网页使用沙箱，不传递本站登录令牌。HTTPS 钱包无法内嵌纯 HTTP 卡网；卡网禁止被嵌入，或其登录/支付流程需要完整浏览器环境时，可用「打开卡网」在新窗口完成购卡。

关闭卡网模式并保存，即恢复原有钱包充值方式。购卡链接和原网关配置均保留。切换不影响历史订单回调、订阅付款、已有卡密兑换及账务统计。

# 收益日报

管理员在控制台侧栏 **管理 → 收益日报**（`/revenue`）查看。以北京时间（UTC+8）为准：今天实时、昨天、近七天、近三十天、全部。近七天和近三十天包含今天；今天在页面可见时每 30 秒刷新，也可手动刷新。

### 消耗、成本和盈利

点击 **绑定成本分组**，选择或输入消耗日志中实际记录的分组名称。填写分组成本倍率，需要时再为该组内某个模型 ID 单独设置倍率。名称精确匹配；模型倍率替代分组倍率，不相乘。删除模型覆盖后恢复继承，`0` 是有效倍率，超过 `1` 可以体现亏损。

- **消耗总价**：日志库中实际记录的计费额度减去退款额度。已包含实际计费时的售价/分组倍率，不按 token 数重新推算价格。
- **预估成本** = 已绑定的消耗净额 × 生效成本倍率；**预估盈利** = 已绑定的消耗净额 − 预估成本。未设倍率的消耗单列，计入总价，不当作零成本盈利。
- 金额跟随站点的余额展示单位。历史使用当前成本倍率估算；修改倍率不会修改用户账单、余额或中转计费规则。「全部」依赖保留的消耗/退款日志，已清理或从未记录的调用无法补算。

### 余额入账

| 来源 | 时间和金额口径 |
| --- | --- |
| 在线充值 | 按成功订单的完成时间和实际入账额度统计，未支付订单、余额支付和订阅镜像订单不计。新版保存每笔真实入账额度；无快照的旧单按支付渠道的入账公式折算。管理员补单仍属于这笔在线充值，不再记作管理员加额。 |
| 兑换码 | 已兑换的面额按兑换时间入账，软删除的已用码仍计入。额外赠金不是主余额，不在该项内。 |
| 管理员添加余额 | 读取已有的管理员「增加额度」记账及其历史回填，以加额时间为准；减额或覆盖余额不是新增充值。 |

**余额入账合计**是这三项的和，不是期末剩余余额，也不是已核实的现金收入。例如用户在线充值到账 100 元、管理员加额 20 元，当天消耗 30 元、成本倍率为 0.6，则入账合计为 120 元，消耗总价为 30 元、预估成本为 18 元、预估盈利为 12 元。入账的 120 元不再加到盈利里。

# 渠道模型专属计费倍率

渠道新增/编辑页的模型专属倍率用于替代最终有效分组倍率，不是重设模型基础价格，也不会与分组倍率叠乘。

## 生效规则

倍率按以下优先级选取：

1. 当前实际使用渠道中，计费模型的专属倍率。
2. 用户所属组对当前使用组的特殊倍率。
3. 当前使用组的默认倍率。

没有配置模型专属倍率时，沿用原有计价规则。全局模型基础价格、输入/输出及缓存价格关系、计费表达式、时长或数量等业务计价规则保持不变。分组权限、令牌模型限制、模型可用性和基础价格配置要求也保持不变。

例如，分组倍率为 `0.5`，某模型设置专属倍率 `0.8` 时，使用 `0.8`，不是 `0.5 × 0.8`。

- 留空或删除一项：恢复继承分组计价。
- `0`：明确免费，不代表未配置。
- `1`：明确使用一倍计费系数，不再享受分组倍率。
- 允许范围：`0` 到 `1000`，含端点。拒绝负数、非有限数值和 `null` 项。

## 模型身份与渠道范围

专属倍率按计费模型名精确匹配：如果配置了令牌模型映射，使用令牌映射后的模型名；不使用渠道模型映射后的上游别名。上游候选模型切换不会改变该计费模型名。此配置不提供正则表达式或通配匹配。

配置属于渠道，而不是分组。同一渠道加入多个分组时，已配置模型的专属倍率会覆盖这些分组的倍率。同组同模型的多个渠道可以设置不同倍率，因此实际售价可能随选路或重试而变化。

请求采用实际成功渠道的计价；每次发送上游前按本次渠道更新计价和预扣。异步任务应使用提交成功时保存的计价快照完成结算，避免后续修改配置影响已提交任务。历史任务保留兼容处理。

## 配置格式

配置保存在现有渠道 `setting` JSON 的 `model_group_ratios` 字段，不需要新增数据库列：

```json
{
  "model_group_ratios": {
    "example-model-a": 0.8,
    "example-model-b": 1,
    "example-model-free": 0
  }
}
```

未列出的模型继续沿用分组计价。清除所有覆盖时，保存不含该字段或包含空对象的完整 `setting` JSON，并保留其他渠道配置。

## 模型广场

选择具体分组后，模型名称附近展示该用户在该组下的实际计费倍率及来源。卡片、表格和详情页使用同一份有效定价数据，显示价格已经包含该倍率，不需要再乘一次。

- 模型专属：渠道中显式设置的模型倍率。
- 用户组特殊倍率：用户所属组对所选分组的特殊计价。
- 分组默认：所选分组的默认倍率。
- 按渠道：候选渠道的倍率或来源不同；倍率及价格按适用范围显示。

同组同模型的渠道价格不一致时，显示最小值到最大值，不将最低价宣称为固定价格。选择全部分组时不展示单一倍率，而以可用分组的有效定价计算最低报价。

倍率是无单位系数，不随币种、每千/百万 Token 展示单位或充值换算选项变化。

## 价格接口

`/api/pricing` 的每个模型可以包含 `billing_ratios`：

```json
{
  "billing_ratios": {
    "default": {
      "min": 0.5,
      "max": 0.8,
      "source": "mixed"
    }
  }
}
```

`source` 为 `channel_model`、`user_group`、`group` 或 `mixed`。结果按当前用户及可用组计算，不包含渠道身份、密钥或完整配置。旧客户端仍可读取原有基础价格和 `group_ratio`，但不能据此准确展示渠道专属售价，升级时应同时部署前后端。
